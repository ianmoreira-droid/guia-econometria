# Replicação dos Exemplos de Econometria de Wooldridge

## Sobre o projeto

Este repositório contém a replicação dos exemplos apresentados nos livros de
Jeffrey M. Wooldridge, utilizando as linguagens R, Python e Stata.

O projeto tem como objetivo servir de apoio aos estudantes que estão usando o
guia de aplicações econométricas, facilitando o processo de aprendizagem do
aluno e possível utilização por professores.

## Estrutura do repositório

Os códigos estão organizados por capítulo e linguagem:

- `Capitulo_01/`
  - `R/`
  - `Python/`
  - `Stata/`
- `Capitulo_02/`
  - `R/`
  - `Python/`
  - `Stata/`
- ...

## Linguagens utilizadas

- R
- Python
- Stata

## Referências

Wooldridge, Jeffrey M. *Introductory Econometrics: A Modern Approach*.
Heiss, F. - Using Python for Introductory Econometrics.
Heiss, F. - Using R for Introductory Econometrics.
